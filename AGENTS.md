# Repository Instructions

## Question quality

- Every question must have one best answer, but the correct answer must not be obvious merely because the other choices are unrelated, absurd, or contradicted by the prompt's wording.
- Keep all four choices plausible within the same architectural decision space. Each distractor should represent a realistic misconception, tradeoff, or near-fit.
- During every question-bank change, review each added or edited question for giveaway wording and weak distractors.
- If a question has only one superficially plausible choice, refactor its prompt or choices. Remove the question if it cannot be made useful without ambiguity.
- Explanations must state the decisive constraint and why each alternative fails it.
